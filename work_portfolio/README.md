# Vishal AI Labs — The Series

An original cinematic portfolio inspired by streaming-service interaction patterns. It does not reuse the reference repository's source code, branding, logos or proprietary media.

## Run

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run preview
```

## Personalise before publishing

1. Edit content in `src/data/portfolio.js`.
2. Replace placeholder links in the `Contact` component in `src/main.jsx`.
3. Add an approved résumé PDF under `public/assets/` and update the link.
4. Replace any case-study wording or metric only with employer-approved public information.
5. The supplied portrait is at `public/assets/vishal-nagare.jpg`.

## Included

- Cinematic opening sequence with skip control
- Three-view profile selector
- Responsive hero using the supplied portrait
- Animated journey, projects, trending row and skill genres
- Full-screen project case-study modal
- Auto-playing highlight reel with keyboard-friendly controls
- Responsive navigation and reduced-motion support
- Original CSS visual system with no external image dependency (Google Fonts is optional)
